# Analysis provenance audit

This note distinguishes the historical analysis helper, the first public
package release, and the frozen revision workflow. These are not identical
code snapshots.

## Historical manuscript analysis

The archived S1-S7 count files were produced with the workspace helper now
preserved as `historical/simulator_YZ_manuscript.R`, rather than the first
public package release. The
relevant historical operations are:

| Reviewer question | Historical analysis code | Finding |
| --- | --- | --- |
| Gene- and cell-type-specific means | `historical/simulator_YZ_manuscript.R`, `generate_gene_pattern()` (lines 167-252) | The function returns one spot-by-gene matrix per cell type. Foreground and background levels were scalar construction parameters, and omitted hotspot parameters persisted after their first draw instead of being redrawn for every gene-cell-type pair. |
| Random seed handling | `historical/simulator_YZ_manuscript.R:172` and `:237-238` | The requested seed was set once at function entry, so the exact nested reset reported for the public package was absent. However, the layer branch called `set.seed(NULL)`, making old layer-pattern runs non-reproducible from the nominal seed alone. |
| Positive-definite repair | `historical/simulator_YZ_manuscript.R:270-279` | The historical helper added the same lift to the complete eigenspectrum before reconstruction and diagonal normalization. This is the uniform-shift family described in the previous rebuttal, not individual clipping. |
| Spot construction | `historical/simulator_YZ_manuscript.R:358-368` | The archived manuscript results use the abundance-weighted spot-level mixture. They were not generated by the later independent-cell revision branch. |
| Additional zeros | `historical/simulator_YZ_manuscript.R:624-639` | Counts were processed by per-molecule binomial thinning. This is not a zero-inflated mixture model. |

An exact reconstruction check reproduced the archived S2 count matrix with
seed 123, 5% binomial thinning, and abundance-weighted aggregation. The
reconstructed and archived files had the same SHA-256 hash:

`7cfd5760c886f20f124d8d48f9524c13fc27241bea270ec96253e2c665e57c4f`

All five archived S2 files have this same hash, so they are duplicate outputs,
not five independent replicates. The archive also contains an identical hash
for S3 replicate 4 and S4 replicates 4 and 5. Because the stored scenario
scripts were edited after those files were generated, and because the layer
branch used `set.seed(NULL)`, the complete 2024 execution state cannot be
recovered exactly for every scenario.

## First public package release

The reviewer correctly identified inconsistencies in the first public package
snapshot:

- `R/patterns.R` reset the seed inside `generate_pattern()`, so repeated calls
  from the gene loop reused the same random stream.
- `R/utils.R` clipped eigenvalues individually even though the rebuttal
  described a uniform shift.
- `R/simulation.R` implemented binomial thinning but the surrounding text used
  zero-inflation terminology.

These release inconsistencies do not establish that the identical code was
used for the archived manuscript outputs. The historical helper above is the
relevant source for that question.

## Maintained package workflow

The package and reproducibility workflow provide an auditable implementation
for new simulations. They:

- sets one top-level seed and does not reset the random-number generator inside
  deterministic pattern helpers;
- samples omitted pattern levels within each gene-cell-type iteration;
- uses the uniform minimum-eigenvalue shift declared in the previous rebuttal;
- applies 5% binomial thinning where specified;
- retains the abundance-weighted spot-level mixture; and
- records five explicit seeds per S1-S7 scenario in `SEEDS.tsv`.

These seeds support deterministic new runs and are not reconstructed
historical seeds. They do not replace the archived inputs used for the
manuscript results.
