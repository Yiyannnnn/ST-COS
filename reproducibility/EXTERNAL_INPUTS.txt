ST-COS EXTERNAL INPUT DECLARATION
=================================

Scope
-----
The reference datasets analyzed in this study are publicly available from the
original studies and associated resources cited in the manuscript: the human
dorsolateral prefrontal cortex (DLPFC) Visium dataset (reference 61), mouse
hypothalamus MERFISH dataset (reference 62), and mouse olfactory bulb
Stereo-seq dataset distributed through the SEDR study resources (reference
63). Raw public data are not redistributed with this repository.

URLs identify the public source;
an accession is reported where the cited resource assigns one. A study or
repository identifier is given when no formal archive accession is assigned.


SHARED REFERENCE-BASED INPUT FORMAT
-----------------------------------
Every dataset (each DLPFC section, MERFISH field, and the olfactory bulb
section) is prepared as two CSV files consumed unchanged by all simulator
scripts in analysis/Reference_based/ (stcos.R, srtsim.R, scdesign3.R,
sccube.py):

1. counts.csv: raw counts, one row per gene and one column per observation
   (spot, cell, or bin). The first column holds unique gene IDs; the header
   holds unique observation IDs.
2. coords.csv: one row per observation. The first column holds the
   observation ID used in counts.csv, followed by numeric columns row and col
   (spatial coordinates) and an optional label column (domain or cell-type
   label; one shared label is used when absent).

Recommended location: data_external/prepared/<dataset_id>/counts.csv and
coords.csv. The dataset sections below state the source files and how each
maps to this format.


1. HUMAN DLPFC VISIUM
---------------------
Study: Maynard et al. (2021), manuscript reference 61.
Study DOI: https://doi.org/10.1038/s41593-020-00787-0
Accession/resource identifiers:
  LIBD spatialLIBD/HumanPilot resource; section IDs 151507, 151508, 151509,
  151510, 151669, 151670, 151671, 151672, 151673, 151674, 151675, and 151676.
  The cited resource does not assign a single GEO-style accession to this
  processed 12-section collection.

Public URLs:
  Counts, one file per section:
    https://spatial-dlpfc.s3.us-east-2.amazonaws.com/h5/<section>_filtered_feature_bc_matrix.h5
  Tissue positions, one file per section:
    https://raw.githubusercontent.com/LieberInstitute/HumanPilot/master/10X/<section>/tissue_positions_list.txt
  Resource page:
    https://github.com/bioc/spatialLIBD

Conversion to the shared format (one dataset per section):
  * counts.csv: the filtered 10x matrix (genes x barcodes), restricted to
    in-tissue spots, non-mitochondrial genes, and genes expressed in at least
    5% of the retained spots.
  * coords.csv: barcode, row = array_row, col = array_col from the tissue
    positions file; optional label = manual layer annotation from the original
    study.


2. MOUSE HYPOTHALAMUS MERFISH
-----------------------------
Study: Moffitt et al. (2018), manuscript reference 62.
Study DOI: https://doi.org/10.1126/science.aau5324
Dataset accession: Dryad DOI 10.5061/dryad.8t8s248
Dataset URL:
  https://datadryad.org/dataset/doi:10.5061/dryad.8t8s248
Original expected filename:
  Moffitt_and_Bambah-Mukku_et_al_merfish_all_cells.csv

Prepared fields used in this study:
  X0_04, X0_09, X0_14, X0_19, and X0_24

Conversion to the shared format (one dataset per field):
  * counts.csv: the field's cells from the Dryad table, transposed to genes x

  * coords.csv: cell ID, row = Centroid_Y, col = Centroid_X; optional label =
    the study's cell class.

4. scCube MODELS AND TRAINING-GENE LISTS
----------------------------------------
scCube (Qian et al., Nat Commun 15, 5021 (2024)) generates data from a trained
variational autoencoder. analysis/Reference_based/sccube.py takes the model
checkpoint (a PyTorch state dict) and the model's ordered training-gene list
(--training-genes; one gene per line, no header). A model must be used only
with its own gene order. Checkpoints are not redistributed. Load checkpoints
only from the sources below, because torch.load unpickles the file.

Released pretrained models (DLPFC and MERFISH)
  The scCube authors list their trained models in
    https://github.com/ZJUFanLab/scCube/blob/main/tutorial/statistics.md
  Each row names a processed AnnData file and the matching checkpoint, and
  gives a Baidu Netdisk download link (access code: cube).

  * DLPFC, all 12 sections: DLPFC_<section>_adata.h5ad and
    slice<section>_epoch100000.pth (18,094 genes).
    Training genes: the var_names of DLPFC_151673_adata.h5ad, in order. All
    twelve checkpoints have an 18,094-gene input layer. Their per-gene decoder
    biases correlate with those of section 151673 (Pearson r = 0.44-0.55,
    versus 0.01 after shuffling genes), so the twelve models share this gene
    order.
    scCube input: unlike the shared format in section 1, the scCube counts.csv
    keeps all genes of the section's filtered 10x matrix (no mitochondrial or
    5% filter) and only in-tissue spots that have a manual layer label;
    coords.csv uses label = that layer. sccube.py reorders the genes to the
    training list and fills the training genes absent from the matrix with
    zeros (15 per section in this study).
  * MERFISH, fields X0_04, X0_09, X0_14, X0_19 and X0_24: the Animal 1 models
    for Bregma -0.04, -0.09, -0.14, -0.19 and -0.24,
    mouse_hypothalamus_MERFISH_Animal1_Bregma_n0.<xx>_adata.h5ad and
    bregma_n0.<xx>_epoch50000.pth (155 genes). The generated outputs used in
    the manuscript have the cell counts listed for these models (5,488, 5,557,
    5,926, 5,803 and 5,543).
    Training genes: the var_names of the matching AnnData file, in order.

Model trained for this study (olfactory bulb)
  No released scCube model covers the olfactory-bulb Stereo-seq data. The
  model used here was trained with scCube's train_vae_and_generate_cell() on
  the prepared olfactory-bulb counts.csv (section 3). Every spot had the
  single label "unknown" (celltype_key = "Cell_type", cell_key = "Cell"), and
  the network used the default architecture with latent size
  hidden_size = 128.
  Training genes: the 8,409 genes retained by the section 3 filter, in
  counts.csv order.
  Checkpoint: MOB_stereoseq.pth.
